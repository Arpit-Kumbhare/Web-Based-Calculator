## Calculator Web Application

This is a clean, responsive, and interactive calculator web app built using core web technologies — HTML, CSS, and JavaScript — without the use of any libraries or frameworks. It simulates the functionality of a basic calculator, capable of performing standard arithmetic operations like addition, subtraction, multiplication, and division.
The project was developed as a practical exercise to enhance skills in:

* DOM Manipulation using JavaScript to dynamically respond to user input,
* Event Handling by capturing button clicks to perform real-time calculations,
* Responsive Web Design with CSS Grid and Flexbox to ensure a consistent layout across various screen sizes,
* And improving UI/UX design by customizing styles, fonts, and interactive elements.
* This calculator serves as a great beginner-to-intermediate level project to understand the synergy between structure (HTML), presentation (CSS), and behavior (JavaScript).

---

## ✨ Features

- Perform basic arithmetic operations: `+`, `-`, `*`, `/`
- `C` button to clear the input
- `=` button to calculate the result
- Responsive layout using CSS Grid
- Styled using Google Fonts
- Handles input through clickable buttons

---

## 🛠️ Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling and responsive design
- **JavaScript (Vanilla)** – Logic and interaction
- **Google Fonts** – Custom typography
